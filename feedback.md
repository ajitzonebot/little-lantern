# Feedback

Mockups: https://claude.ai/artifact/RZKqBTLJBdYfthjQzBuEa3

How notes get here:
- In the app: tap **Feedback** (top right of every screen). The note is filed under the screen it was written on and committed here by the app. Set the GitHub token once in Parent mode, Feedback.
- On the mockups: comment on a screen in the canvas and send it to Claude, who adds it here.
